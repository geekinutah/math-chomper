# Math Chomper

A browser math-fluency game. Eat the numbers that match the rule. Avoid the enemies.

Behavior is in `PRODUCT_SPEC.md`. How agents build it is in `AGENTS.md`. The ledger is `STATUS.md`.

## Getting started

Requires Node 20.19+, 22.12+, or newer.

```
npm install
npm run dev
```

Then open http://localhost:5173.

Other commands: `npm test` (Vitest), `npm run typecheck`, `npm run build` (emits `dist/`, which opens by itself from `dist/index.html`).
